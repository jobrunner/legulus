# Foto-View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Serienkamera wird zur Vollbild-Foto-View mit Blüten-Stufen (Auto/Fokus fest/Makro), Blitz mit LED, Galerie-Import und Zoomrad.

**Architecture:** Reine Logik als `nonisolated static` Funktionen bzw. kleine Werttypen neben `CameraSession` (wie heute, getestet in `CameraSessionLogicTests`). AVFoundation bleibt in `CameraCore` auf dessen Queue. `CameraView` legt die Bedienelemente als Overlay über eine randlose `CameraPreview`. Drei PRs, jeder auf eigenem Branch von `main`, jeder für sich lauffähig.

**Tech Stack:** SwiftUI, AVFoundation, PhotosUI (`PhotosPicker`), XCTest. iOS 17.

**Spec:** `docs/superpowers/specs/2026-11-24-foto-view-design.md`

## Global Constraints

- Deployment Target iOS 17.0; Testgerät iPhone 14 Pro.
- Englische Bezeichner, deutsche UI-Texte über `Localizable.xcstrings` (Literale, `LocalizedStringKey`, `String(localized:)`); neue Schlüssel in den Katalog.
- Zahlen (Zoomfaktor) nach Locale formatiert, z.B. `1,4×` in `de`.
- Nur Tokens aus `Core/Theme/` und Atoms aus `Core/UI/`; keine Magic Numbers, keine festen Animationsdauern (`AppMotion`), Reduce Motion über `AppMotion.respecting(...)`.
- `ACCESSIBILITY-IOS.md`: jedes Element ≥ 44 × 44 pt, Label/Value an jedem Knopf, nichts nur per Geste erreichbar, Statusansagen per `AccessibilityNotification.Announcement`.
- Logging nur `Log.ui` / `Log.persistence`, kein `print()`, keine Koordinaten `.public`.
- Keine Force-Unwraps.
- Die View-Schnittstelle bleibt `CameraView(onPhoto: (Data) throws -> Void, onDone: () -> Void)`; `SampleEditorView` ändert sich nicht.
- Jedes Öffnen startet in Fokus-Stufe Auto und Licht Automatik.
- Commits: Conventional Commits, Scope `ios`, mit Zeile `Claude-Session: https://claude.ai/code/session_015iSEsUFszdKAKenpSWPu4X`.
- Verifikation jedes PRs: `bash scripts/check-ios.sh` grün, danach Gerätetest durch Jo.

## Review Focus

1. LED bleibt an, wenn die App in den Hintergrund geht, der Picker offen ist oder die Kamera schließt → Licht muss aus sein. Test in Task 1 (`torchShouldBeOn`).
2. Auslöser während des Objektivwechsels (Schwarzbild) → Aufnahme wird ignoriert, nicht gezählt, kein Absturz. Test in Task 5 (`canCapture`).
3. Galeriefoto lädt nicht (nur in iCloud und offline, Konvertierung scheitert) → Fehlermeldung, die übrigen ausgewählten Fotos werden trotzdem gespeichert und gezählt. Test in Task 4.
4. Gerät ohne Torch / ohne nahes Ultraweitwinkel → Zyklus überspringt die fehlende Stufe, kein toter Zustand. Tests in Task 1 und Task 5.
5. Versehentliches Tippen in „Fokus fest“ → Fokus bleibt, nur die Belichtung wandert. Test in Task 5 (`tapAction`).
